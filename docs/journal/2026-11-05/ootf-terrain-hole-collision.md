# Terrain holes and the tavern cellar

The converter retained hole texture references but dropped native triangle collision flags. PAL function 15a2f0 reads each cell's flags and skips its first triangle when 0x40 is set and its second when 0x80 is set; otherwise it calls intersection routine 1c51e0. The texture sentinel alone does not remove collision. A direct audit of 15 disc LVLs finds all 79,493 hole cells have 0xc0 and all 161,655 invisible cells have 0x30. Invisible cells retain collision. Private native exports and the census remain under `build/scratch/terrain-flags-root` and `native-terrain-flags.json`.

`ps2CellFlags` now derives 0xc0 for full holes and 0x30 for invisible cells from the converted texture reference, retaining the existing diagonal and other supported source bits. Conversion also clears the corresponding vertex adjacency bits around holes, matching the existing disc-terrain editor writer. The serialized regression checks the actual native flag words and distinguishes invisible floors from holes.
