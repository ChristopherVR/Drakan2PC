A continuation from the fresh, normally completed CD09 corrected-header opening reached the source Atimar actor using ordinary movement. The item did not appear in the inventory UI. This was initially described as a ground pickup failure; that framing was wrong. `parsePcObjects` already translates raw PC link positions into object IDs. A temporary read-only audit incorrectly treated the resulting IDs as indices. The actual source Rynn object1740 links directly to Atimar1059: it is a starting-inventory object. The earlier apparent association with Visibility Toggler2731 came from that audit mistake and is withdrawn. Native disabled world state alone is therefore not a defect.
