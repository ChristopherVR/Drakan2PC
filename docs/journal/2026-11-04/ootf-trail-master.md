# Native-backed OotF Trail Master effects

PAL registers the Trail Master runtime class (0x10051, rfl81), its eighteen-field descriptor and a real actor handler at 0x4238e8. Initialization at 0x423ae8 creates the referenced tracer through the ordinary world factory. Thus the missing original ODB template does not imply missing engine support. The PC Solve Magic FX Right/Left and Rim Phase FX R/L schemas were compared by ordered field semantics and types against this native descriptor. Their referenced Solve Magic Tracer is rfl60, for which the native ODBs already contain compatible templates.

The converter can now synthesize this specific verified rfl81 schema without borrowing an unrelated class. It requires exact ordered PC editor field names and types, an explicitly converted model, destination-aware bounds, and positive confirmation that the model is rigid. Reordered float fields, changed types, missing model/bounds and skinned or unverified models are rejected. The class uses an existing native group, the correct runtime id, model marker and zero auxiliary header companion. Source tracer references are relocated after complete class planning. Rfl60 is classified as an effect so referenced tracer and weapon-ribbon source models and their textures follow the existing asset conversion path.

Regression coverage verifies the valid record layout and model binding, typed class relocation, rejection of reordered same-type fields, rejection of skinned/unknown models, and conversion of referenced rfl60 models. The complete formats suite passed 326 tests across 30 files; TypeScript compilation passed.

The separate generated candidate is `build/scratch/ootf-trail/mods/ootf-levels.zip`, SHA256 `7BA5B1FB7764A9CD913D81327ED63AF7FC36BBF3A5EAF4CF9B1472174436319C`. It contains 2,140 synthesized classes with zero dangling emitted class references. All 1,830 referenced models resolve against generated and available original archives; 37 references belong to original archives not extracted for this audit and remain unverified. The Solve Magic generators now reference both rfl81 effects and their fountain. The four rfl81 records reference RESOURES18477, the converted rfl60 Solve Magic Tracer. Their source models are rigid quads with actual local TXD texture entries. All four parent headers and the tracer cache bounds exactly matching their destination MOD 0x0207 data; every synthesized header has a zero auxiliary companion. Private evidence is under `build/scratch/ootf-trail/audit/`: `classrefs.json`, `modelrefs.json`, `trail-assets.json`, and `trail-headers.json`.

This establishes native dispatch support and a coherent emitted resource closure, not a live quest-effect or campaign-completion result. The corrected-current normal-opening candidate remains separate and unchanged. A later real Solve Magic/Rim Phase interaction still needs visual validation during normal progression.

Poison Gas (rfl69) remains explicitly unsupported by this change. Its native schema/metadata exists despite there being no shipped ODB template, but an executable native poison handler or equivalent dispatch has not yet been established. The converter does not substitute another engine id or claim that an inert schema alone implements poison damage.
