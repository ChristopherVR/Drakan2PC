Install

Install Drakan on your PC

The game is built on your own computer from your own disc image. Pick where you want to play and follow the steps. It takes about five minutes to read and one to two hours to build.

  1. Check your disc

    You need your own PAL SCES-500.06 disc image (the USA SCUS-971.28 disc also builds, as an experimental version with keyboard and mouse but without the PC settings, widescreen, quicksave or modern menus; its saves are separate) as a plain .iso. The builder checks it and stops if it does not match. Keep the file in a stable folder, because the game keeps reading it while you play.

  2. Check your PC

    Windows 10 or 11 (64-bit), at least 16 GB of memory (24 GB recommended), about 10 GB of free disk space, a DirectX 11 GPU and an internet connection for the first tool downloads.

  3. Download and run the installer

    Download DrakanPC-Setup.exe from the latest release, run it, then choose an install folder and your ISO. Leave Build the game now ticked. Optional components such as NVIDIA DLSS and the browser version are listed on the same screen.

  4. Wait for the build

    Leave the build window open until it says it has finished. Some large steps print nothing for about ten minutes. Windows may ask permission to install Microsoft's C++ Build Tools.

  5. Play

    Launch Drakan - The Ancients' Gates from the desktop or Start menu. Press F1 for PC Settings, F11 for fullscreen and F10 to release the mouse.

  1. Check your disc

  2. Check your system

    x86-64 Ubuntu or Debian with build tools, enough memory for the larger compilation steps and about 10 GB of free disk space. The Linux guide lists the exact packages.

  3. Get the source

    Clone the repository from GitHub and install the packages named in the guide. Everything runs from a terminal in the project folder.

  4. Build from your ISO

    Run the Linux build script with the path to your ISO. The first build takes one to two hours; later rebuilds are much faster and keep your saves.

  5. Play

    Start the player from dist/DrakanPC-linux. Press F1 for PC Settings.
